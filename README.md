# Lançamento de Notas

Sistema que lê arquivos CSV exportados do Google Forms, calcula a média
dos alunos e informa a situação (aprovado/reprovado).

## Como usar
1. Instale o Python 3 e rode: pip install -r requirements.txt
2. Coloque os arquivos .csv na pasta `dados/`
3. Rode: python main.py

## Funcionalidades
- Leitura de múltiplos CSVs
- Busca por R.A
- Lista de aprovados e reprovados
- Exportação de relatório
